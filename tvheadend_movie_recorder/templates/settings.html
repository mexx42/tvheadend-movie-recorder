Tvheadend

Inside Docker, localhost is the container itself. Use the server's LAN address.

Leave empty for Tvheadend's default recording profile.

Saves each request and answer, including the programme guide, to help find problems. Passwords and user names are never recorded; titles and descriptions are. Review the file before you share it. The log is capped at a few MB. Turn this off when you are done.

TMDb

Used to find the cast and crew of a movie when the guide text does not name them. Get a free key at themoviedb.org. Without a key only the guide descriptions are searched.

Language of the guide titles, e.g. de-DE or en-US.

At most 180 days: TMDb's terms do not allow keeping their data longer than six months.

Recording

Time of day in the container's time zone (TZ in docker-compose.yml). If the container was off at that time, the run happens at the next start. To run on your own schedule instead, untick the box above and call python -m tvheadend_movie_recorder run from cron (see the README).

Shown as a link in the text report of the run command. Use the address you open from another device, not localhost.
